# 模式 A：完全复刻参考视频

## 替换维度

替换维度由素材决定，有对应图片即默认替换；需求描述明确要求保留某维度时以需求描述为准。

- **产品**：默认替换（没有新产品就不存在复刻任务）。
- **人物**：有「人物图」即替换为图中人物。没有人物图时看原片人物和产品怎么打交道（拆解文件第 4 节有记录）：他穿戴、实穿试用产品，新人物就必须是新产品的可信使用者——儿童产品的穿着者就是儿童；他只是手持讲解、带货展示，新人物不必是使用者，按需求描述和受众沿用同类人设即可。同一人两种镜头都有的，按使用者定。需求描述里「服装/动作和参考视频一致」说的是样式与节奏照原片，不是把原片人物搬进新片：人物的年龄身形换了，原人物的着装风格就按新人物改写。
- **场景**：有「场景图」即替换为图中场景；没有则 1:1 继承参考视频场景。

## 改编边界

- 景别、机位、运镜、镜头切换方式、动作轨迹和整体节奏 1:1 继承参考视频（结构层级与镜头划分照 `storyboard-spec.md` 镜头继承规则）。
- Storyline 每镜正文照抄拆解文件第 4 节原文，只把被替换实体的名称与外观词换成角色设定块里的对应描述；切换方式、景别、机位运镜、动作序列、背景元素、声音一个字不改。道具（滑板、杯子这类）不是替换维度，原样保留，不添外观。照抄的例外只有两处：`{ }` 里的台词随新产品改写；在新产品上不能完成的动作改为演示需求描述里的卖点。
- 对白不复刻：保留原对白的话语功能、断句节奏和出现位置，内容随新产品的名称、卖点和使用方式改写。

## 展开路径

先读拆解文件第 3 节「出场清单」定全片替换范围：

1. 出场清单与素材事实清单同为人物、产品、场景三类，逐行比对，标出哪些被替换、哪些 1:1 继承。
2. 出场清单有而素材事实清单无对应条目的维度，按上方「替换维度」规则处理。
3. 素材事实清单有而出场清单无的实体，不新增进片子。
4. 「出场清单」小节缺失时，改为逐行读第 4 节 Storyline 归纳出场实体，再按上述规则比对。

范围确定后逐镜执行：先照抄该镜原文，再替换被替换实体的名称与外观词——人物换成人物名与锚点里的外貌、服装，产品换成产品名与产品事实清单里的外观，场景换成场景名与场景图里的环境；然后把 `{ }` 台词在原位置、原断句节奏上按新产品的名称、卖点和使用方式改写。替换后，逐个检查镜头里与产品接触的动作在新产品上是否仍能完成：新产品没有该部位、该部位在此景别下看不见或手触不到、穿脱方式不同，都算不能完成（原片按压乐福鞋的鞋垫，及膝长靴的鞋垫藏在靴筒里看不见）。不能完成的动作改为演示需求描述里的卖点，优先该镜台词讲到的那一个（台词讲侧拉链，就改为拉开再拉上侧拉链）；景别、机位、时间码和其余动作照抄，前后镜头不动。

## Storyline 写法

- 被替换维度的描述只来自对应图片的直接观察；未替换维度的描述只来自拆解文件第 4 节。
- 参考视频中的配角、背景路人和辅助道具关系，在不与替换维度冲突时原样保留，不得打乱原有铺垫。
