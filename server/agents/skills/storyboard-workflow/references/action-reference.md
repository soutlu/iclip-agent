# 模式 C：完全复刻参考视频动作

## 改编边界

- 动作骨架 1:1 复刻：每个动作节拍的物理方向、力度、幅度、速度、推进顺序和戏剧功能必须逐拍映射自拆解文件第 4 节，节拍数量和顺序不变。
- 景别、机位、运镜和切换位置照原片执行（结构层级与镜头划分照 `storyboard-spec.md` 镜头继承规则）。
- 人物、场景、产品和对白全部重写：内容来自素材事实清单、基础信息和需求描述，不继承参考视频的人物身份、环境和台词内容。

## 展开路径

逐结构层级执行，每个层级按以下顺序展开为 Storyline：

1. 提取动作骨架：从拆解文件第 4 节提取该层级的核心动作节拍序列（物理动作的起、承、转各是什么），记录每个节拍的时间位置、景别、机位运镜和戏剧功能。
2. 映射新主体：把新人物、新产品、新场景填入同一节拍位置；填入时只替换主体身份和环境，不改变动作的物理方向、力度和推进顺序。
3. 重写对白：在原对白断句位置写入新对白，内容围绕新产品的卖点和使用场景，保持相同的句长、停顿和反应模式；情绪爆发点必须落在原片相同的节拍位置，可以更换触发原因但不能移位或删除。
4. 铺垫检查：新环境中后续会互动的人物、道具或空间关系是否已在前序镜头出现；未出现则在最近的合理位置补入铺垫动作，不新增结构层级。

## Storyline 写法

动作描写对齐原片动作节拍，写节拍如何发生而不只写动作结果；新主体的描述只来自对应图片的直接观察与素材事实清单，动作、镜头和节奏只来自拆解文件第 4 节。
