契约范围　本页第一个 <style> 内 :root 与 .dark 两块中除 --pg-* 外的全部变量。运行时 web/src/app/globals.css（@theme）与 base.css（:root / .dark）逐名逐值镜像；比较时去掉全部空格后逐字相等。
对账　本页有而运行时无、值不同、运行时有而本页未登记，三者均报错。新增 token 先写本页，再镜像运行时。对账脚本附带注入漂移的自测。
消费　组件不加载、不解析本文件；颜色只经 ②③ 层，尺寸只经 ④ 层。主题切换：<html> 加减 .dark（@custom-variant dark (&:is(.dark *))），默认跟随 prefers-color-scheme，用户选择存 localStorage。
门禁　pnpm lint:design = 对账 + design-guard（裸色值、表外字号 / 圆角 / 阴影 / 动效、Tailwind 原色板类、内联 style 颜色）。ESLint：lucide-react 只许 shared/icons、radix-ui 只许 shared/ui import。豁免须带理由：// design-allow -- 原因。

规则做法
装饰性图标旁边已有文字表达同一含义 → aria-hidden，不带 label
语义性图标单独承载含义（图标按钮、状态点）→ 必须传 label，缺失时组件直接抛错，不静默降级
加新图标只在名字表里加一行：语义键 → lucide 组件。键名按用途起（search close run），不按图形起
改名 / 删除一次迁完全部调用点，不留旧名兼容别名（IconName 类型会把漏网处报成编译错误）
颜色永远 currentColor，由父元素文字色决定；状态色用 §02 的语义色包一层
存量内联 <svg>通用图标迁进名字表；品牌 / 插画留在 shared/ui/icons，门禁按数量棘轮只降不升

14 · 收敛原则与变更流程Governance
① Token 优先　颜色、字号、圆角、阴影、时长、层级、控件高度一律取现有 token；没有则先加入本页，再镜像运行时。代码不出现字面值。
② 模板只管结构　骨架定槽位、尺寸、底色、层级；内容与业务判断属 feature。feature 不覆写槽位规格，模板不含业务文案。
③ 两处复用再上收　只在一个 feature 使用的组件 / 样式留在该 feature；第二个 feature 复用时进 §05 契约表并上收 shared/ui。不预先抽象。
不做兼容别名　改名或删除 token、变体、图标时一次迁完全部调用点并删旧名。
步骤做什么怎么验证
1 改规范在本页对应章节改 token / 契约表 / 矩阵；颜色类同时补 .dark浏览器打开本页看效果（浅色卡与深色卡）
2 镜像运行时base.css / globals.css 同名同值；工具类经 @theme inline reference 自动出pnpm lint:design 对账通过
3 改组件契约表变了才动 shared/ui；feature 只消费pnpm lint（ESLint 入口锁）· pnpm typecheck
4 清存量门禁报出的裸值、表外档位当次改完，不留基线pnpm lint:design 全绿
5 浏览器 QA桌面 + 紧凑两档、浅色 + 深色两套截图截图落 gitignore 的 .artifacts/design-qa/，不进仓库
6 提交make web-check 全绿后发 PRCI 双端绿
