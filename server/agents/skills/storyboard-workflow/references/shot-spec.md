# 镜头组 Prompt 表规范

## 事实源

只以 `storyboard.md`（角色设定块与逐镜拉片表）为生成依据：按顺序读取 Storyline 中的时间戳、景别与机位、动作、对白、场景、画面主体和产品露出，不增不减。参考视频拆解、用户原始故事或图片观察结果只可用于理解创作上下文，不能替代逐镜拉片表中的景别、机位、动作、对白或时间戳。

字幕、图标、贴纸、标签、动态花字等非实拍画面元素在转写时删除。

## 镜头组切分

切点只落在结构层级边界上：逐镜拉片表一行是一个结构层级，结构层级之间是唯一的候选切点——结构层级本身就是视频的叙事骨架，切在这里不会切断动作或对白。结构层级内的镜头（Storyline 中一个 `**[MM:SS.mmm-MM:SS.mmm]**` 及其对应内容）不作为切点。

切分按以下规则执行：

1. 先观察整个视频的长度，如果整个视频不超过 30 秒就不切分，直接作为一个镜头组。
2. 在视频长度超过 30s 时，按场景组合结构层级：自上而下逐结构层级累加，直到遇到场景变化（Storyline 中的场景切换）时在此切开，下一结构层级起算新的镜头组。算例：4 个结构层级 10 / 11 / 10 / 14 秒——第 3 个结构层级与第 4 个结构层级场景不同，在第 3 个结构层级前切开，形成两个镜头组（10+11=21 秒、10+14=24 秒）。
3. 在场景组合的基础上，如果有镜头组不足 4s 的，就把前一个镜头组的最后一个结构层级并入当前镜头组。从前一个镜头组减去最后的那个结构层级，保证全部镜头组的时长都在 4-30 秒之间。算例：4 个结构层级 10s / 11s / 8s / 2s ——第 4 个结构层级不足 4 秒，把第 3 个结构层级并入第 2 个镜头组，形成两个镜头组（22 秒、8+2=10 秒）。

切分结果自检：按顺序核对每一对相邻镜头组，两者时长之和必须大于 30 秒（否则第 1 步本该把它们并成一个）。

切分定下的顺序即 `index`，从 1 连续编号。

## 参考图

`image_urls` = 该镜头组的全部镜头帧 URL，按帧号排序（先镜头号，同一镜头号内按序号）；URL 逐字取自 `generate_shot_frames` 返回值，不得自行编造。按列表顺序在 prompt 中编号为 `@Image1`、`@Image2`……`@ImageN`，每个 `@ImageN` 都必须能映射到 `image_urls` 第 N 项。

镜头帧紧跟在描绘它的那段文字之后，像标注一样嵌在句子中间：`双手将皮鞋举至胸前 @Image6，拇指按压鞋头感受回弹`。每个镜头帧的位置要按正确的镜头号放在正确的镜头描述中。一个镜头内有多张帧时按序号先后各自贴在对应的分句后。

人物、产品与场景的外观由镜头帧承载，不引用原始参考图；外貌、材质与场景的文字描述在时间线首次出现处交代，与 `storyboard.md` 角色设定块一致。

## Prompt 结构

prompt 是一条自然叙事时间线，按时间码顺序描述每个镜头的景别、机位、运镜、主体动作、对白和产品交互，镜头帧紧跟描绘它的那段文字；末尾固定写 `不要字幕，不要背景音乐。`

```text
0-4s 全景 平视机位 固定，[人物首次出现，带外貌关键词] @Image1，[环境与声音]。
4-9s 中景 侧面平视 镜头缓慢右移，[主体动作] @Image2，[声音]。
9-14s 正面特写 平视机位 无缝硬切，[主体动作] @Image3，[后续动作] @Image4。
不要字幕，不要背景音乐。
```

- 每个镜头组的时间码从 `0s` 归零：原始 `09-11s / 11-15s` 写成 `0-2s / 2-6s`。
- 每个镜头组是独立的生成单元，prompt 自包含全部人物外貌、场景和产品描述，不引用其他镜头组的内容、不写"延续镜头组 1"。
- 多个镜头合并进一个镜头组时，时间线仍按镜头逐个写，镜头之间写明切换方式（硬切、转场或运镜衔接）；场景、光线和人物状态只在首次出现的镜头交代，后续镜头只写发生变化的景别、机位、动作、对白和产品交互，不重复相同的背景描述。
- 画面与镜头描述使用简体中文；品牌名、型号、URL、`@ImageN` 与 `{ }` 里的台词保持原文。
- 只写应出现的内容，不用"不要""禁止""避免"等否定句式；末尾的 `不要字幕，不要背景音乐。` 是输出约束，不受此限。
- 只写可被画面或声音直接验证的描述：用动作、位置、光源和材质陈述，景别、机位、运镜、光效和色调使用具体术语（如中景、低角度仰拍、推镜头、体积光、丁达尔效应、青橙色调）；"气质""高级感""治愈"等不可量化的词不写。

### 声音

声音随所在镜头一起写，按类别用各自的记号：

- 对白与旁白：台词用 `{ }` 包裹，前面写明语种、说话人与表达方式，如 `男人用自然口语化的美式英语说 {Exceptional quality.}`；无出镜说话人的旁白写明语种与音色。台词逐字取自逐镜拉片表，不翻译、不改写、不更换语言。
- 环境音与动作音效：用 `< >` 包裹，写声源、音色与起止，如 `<鞋跟敲击木地板两声>`；不写"轻快的音乐""氛围感拉满"这类无声源的情绪修辞。
- 配乐与 BGM 后期铺，不写进 prompt：Storyline 里的配乐描述（鼓点渐入、推至高潮）在转写时丢弃，与末尾固定的 `不要背景音乐。` 保持一致。

## Prompt 示例

### 示例镜头组 1（时长 28 秒，`image_urls` = 本镜头组 8 张镜头帧）

> 0-4s 全景 侧面平视 固定机位，核心人物——35 岁左右白人男性，穿驼色高领毛衣与深灰色羊毛长裤，深金色短发梳理整齐，左手戴银色腕表——背对镜头站在整墙实木书架前 @Image1，右手扶住书架立柱，晨光从右侧高窗斜切进来在地板上拉出长条光斑，<窗外零星鸟鸣>。4-9s 中景 侧面平视 镜头随他缓慢右移，他侧身从书架第三层取出一只焦糖色布洛克皮鞋，皮鞋脱离木架时鞋跟朝下悬在半空 @Image2，<鞋底离开木架的轻微摩擦声>。9-13s 正面特写 平视机位 无缝硬切，双手将皮鞋举至胸前 @Image3，拇指按压鞋头感受回弹，<皮革被指腹按压的细微咯吱声>。13-18s 特写 侧上方俯拍 镜头平滑下移，手指沿鞋侧拼接线滑过 @Image4，随后鞋跟缝线整段入画 @Image5，<指腹划过皮面的沙沙声>。18-22s 近景 平视机位 无缝硬切，他把皮鞋斜举向窗边光源缓慢转动手腕 @Image6，鞋头雕花孔眼的阴影随转动在皮面上流动。22-25s 中景 正面平视 镜头轻微后拉，他把皮鞋换到左手、右手拂过鞋帮除去浮尘 @Image7。25-28s 中景 侧面平视 镜头缓慢拉远，他把皮鞋放回书架原位后退开半步 @Image8，目光扫过整排鞋子最终落回这一只。不要字幕，不要背景音乐。

### 示例镜头组 2（时长 20 秒，`image_urls` = 本镜头组 5 张镜头帧，含英文对白）

> 0-4s 极近距离特写 平视机位 固定，核心人物——35 岁左右白人男性，驼色高领毛衣与深灰色羊毛长裤——坐在明亮试鞋区的深棕皮革长凳旁，双手拇指按住焦糖色布洛克皮鞋后跟向内压 @Image1，鞋跟回弹后恢复原形，<皮革受压回弹的闷响两声>。4-8s 中近景 平视机位 无缝硬切，他双手分别握住鞋头与鞋跟，平缓将鞋身对折至约四十五度 @Image2 再松开。8-13s 特写 平视机位 镜头缓慢推近，他将鞋口朝向镜头、手指撑开内部衬里 @Image3，核心人物用自然口语化的美式英语轻声说 {Exceptional quality.}。13-17s 中景 正面平视 镜头轻微后拉，他把皮鞋鞋底朝下平放在长凳上 @Image4，双手撤离画面，<鞋底接触皮革凳面的一声短促闷响>。17-20s 近景 侧面平视 固定机位，他点头看向镜头 @Image5，右手食指轻点鞋面侧孔两下。不要字幕，不要背景音乐。

## 交付

交付前逐个核对 prompt 里的 `@ImageN`：帧号里的镜头号（`S5-2` 属镜头 5）必须与贴它那段文字所属的镜头一致，不一致就挪进正确的镜头段落。

调用 `write_video_shots`：`aspect_ratio` 传目标画幅，`shots` 逐个给出 `index`、`prompt`、`seconds` 与 `image_urls`。`seconds` 是整数，取该镜头组覆盖的各结构层级时长之和四舍五入到秒，范围 4-30 秒。
