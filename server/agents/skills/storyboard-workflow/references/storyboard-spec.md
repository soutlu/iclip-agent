# 逐镜拉片表共同法度

两种改编模式共用的规则：镜头继承、硬约束、粒度标尺和 `storyboard.md` 文件格式。模式专有的替换范围与改写边界在模式 reference 中。

## 镜头继承规则

结构层级与镜头划分逐个继承参考视频拆解文件第 4 节逐镜拉片表的结构：不增删、不拆分、不合并、不重排，两侧数量严格相等。

- 结构层级即拉片表的一行，顺序、名称照抄；参考视频某结构层级有 2 个镜头，改编后就是这 2 个镜头。
- 镜头数是硬约束：`storyboard.md` 继承同一份结构。
- 时间码起止照抄参考视频。仅当新产品的物理交互耗时与原镜头不兼容时允许轻微调整，只允许调整当前镜头；对白装不下调整对应镜头的时间码。
- 目标时长与参考视频不一致时，全部时间码按「目标时长 ÷ 参考时长」等比缩放，相对节奏原样保留；缩放后再按对白容量规则微调。用户给定的对白按语速估算连全片都装不下时，对白一字不删，总时长放宽到装下为止，在最终回复报人工复核。

## 共同硬约束

- Storyline 中每一处产品名称、颜色、材质和设计细节必须来自产品事实清单；禁止沿用参考视频原产品的外观描述，禁止把非产品人物图中的服装当作产品。
- 出场人物的外貌、服装、发型描述必须与角色设定块中该人物那一条一致：人物在 Storyline 首次出现时用基准关键词完整交代，后续镜头不得出现与基准冲突的属性。
- 自行撰写的对白保持口语化、短句、断句和即时情绪，每句不超过 15 个单词；语言使用需求描述要求或用户已提供对白的语言，未指定时按目标受众选择，全片保持一致。用户提供的对白原文不受此限。
- 后续会互动的人物、道具或空间关系必须提前铺垫，避免突兀出现。
- 「出场人物/产品」列逐行标注该结构层级出场的人物与产品：人物用角色设定块的人物名，产品用产品名（单产品用品类词）；无人物或无产品的行只写实际出场的类型。单人单品视频该列照写全片常量，不省略。
- 文件正文只包含角色设定块与逐镜拉片表：不输出 JSON、不加代码块、正文前后不追加说明文字，不写拍摄建议、生成建议、执行要点、镜头节奏与 BGM 对照、连续性检查、转场逻辑说明或其他附加章节。

## Storyline 粒度标尺

正确的 Storyline 是一段按时间推进的动态叙事，信息密度介于"过粗"和"过细"之间。

正确粒度——每个镜头写清景别、机位运镜、主体动作序列、产品交互、环境氛围和声音提示，全部用连贯叙事串联：

> **[00:06.000-00:09.500]** 中景侧方跟拍，东亚短发男性穿着黑色连帽户外夹克与黑色多口袋工装长裤，沿林间落叶小径稳健行进，镜头与他同步移动，焦点始终锁定鞋与泥土地面的接触，背景是深绿与墨绿交织的林间植被，光线为穿过树冠的斑驳日光。

过粗——只写静态总结或抽象意图，无法据此拍摄或生成画面：

> 男子在户外跑步，展示产品防滑性能。

过细——把 Storyline 拆成逐镜子表格、加镜头编号列、加参考图列、加"与原片对照"段落，或在表格外写章节标题和叙事段落：

> | 镜号 | 时间码 | 景别 | 机位/运镜 | 画面内容描述 | 人物/产品动作细节 | 参考图提示 | 音效/BGM |

Storyline 单元格内只使用 `**[MM:SS.mmm-MM:SS.mmm]**` 精确时间码开头的文本段落和 `<br><br>` 连接，不使用子表格、列表、标题或其他结构化标记，不写模糊时间表述。

## 逐镜拉片表文件格式

目标文件路径为 `storyboard.md`，内容由角色设定块和完整 Markdown 逐镜拉片表组成：

```markdown
## 角色设定

- [人物「实体名」：性别年龄 + 体型身形 + 肤色与面部特征 + 发型发色 + 服装版型/颜色/材质 + 标志性特征]
- [产品「实体名」：品类 + 主体配色分区 + 材质与结构部件 + 关键设计细节 + 品牌标识及其位置]
- [场景「实体名」：空间类型 + 核心陈设 + 材质]

## 逐镜拉片表 (Shot-by-Shot Script)

| 结构层级 | 出场人物/产品/场景 | Storyline |
| :--- | :--- | :--- |
| 原表第 1 行结构层级名称 | 人物、产品A | 改写后的 Storyline |
| 原表第 2 行结构层级名称 | 产品A、场景 | 改写后的 Storyline |
```

- 冒号前是类型加实体名，冒号后是该实体的锚点。实体名一律写：素材清单里有的取其名称列（单产品即品类词），推断补充的实体起一个辨识性短名。它是全流程的指代键——「出场人物/产品」列、visual_prompt 与 global_reference 都用它点名。
- 条目逐槽位写满，不用"一个男孩"这类模糊描述。
- 人物条目逐个出场人物一行，无出场人物的视频省略；场景条目按全片出现的场景逐个一行；产品条目逐产品一行，同一产品的多个视角合成一条。
- 同一结构层级中包含多个连续镜头时，继续放在同一个 `Storyline` 单元格内，用 `<br><br>` 连接。
