# 模式 B：完全复刻参考视频动作

## 替换维度

人物、场景、产品、对白四个维度全部替换，不看素材里有没有图。拆解文件第 3 节「出场清单」只决定要锚定几个实体，不作为任何维度的取值来源。

- **产品**：按产品事实清单替换。
- **人物**：有「人物图」即替换为图中人物；没有人物图时不沿用原片人物，从目标受众与产品使用者定一个新人物。
- **场景**：有「场景图」即替换为图中场景；没有场景图时不沿用原片环境，从使用场景定一个新场景。
- **对白**：内容全部新写，围绕新产品的卖点和使用方式；原片台词的内容与出现位置都不继承。

## 改编边界

- 动作骨架 1:1 复刻：每个动作节拍的物理方向、力度、幅度、速度和推进顺序逐拍映射自拆解文件第 4 节。
- 景别、机位、运镜、镜头切换方式和切换位置照原片执行（结构层级与镜头划分照 `storyboard-spec.md` 镜头继承规则）。
- 每个动作在新片里表达什么——展示哪个卖点、推进哪段情节——由需求描述与核心卖点决定，不继承原片的叙事功能与情绪起落。
- 视听风格块照抄拆解文件第 5 节，光线与色调那一句按新场景改写。

## 展开路径

逐结构层级执行，每个层级按以下顺序展开为 Storyline：

1. 提取动作骨架：从拆解文件第 4 节提取该层级的核心动作节拍序列（物理动作的起、承、转各是什么），记录每个节拍的时间位置、景别和机位运镜；剥掉原片人物、产品、场景的身份与外观描述。
2. 判断物理兼容性：对每个产品交互节拍，比对新产品的握持方式、使用步骤数和体积与原产品的差异——
   - 兼容：动作轨迹不变。
   - 单镜头不兼容：该镜头的动作序列按新产品实际使用方式重写，时间码允许微调，前后镜头不动。
   - 连续动作链不兼容：以最少的几个连续镜头为一组重写动作序列，保持该组所属结构层级的节奏位置不变。
3. 映射新主体：把新人物、新产品、新场景填入同一节拍位置；填入时只替换主体身份和环境，不改变动作的物理方向、力度和推进顺序。
4. 定卖点与对白：写明该层级在新片里表达哪个卖点；需求描述没给对白时，围绕这个卖点新写对白。

## Storyline 写法

- 动作描写对齐原片动作节拍，写节拍如何发生而不只写动作结果；新主体的描述只来自对应图片的直接观察与素材事实清单，动作、镜头和节奏只来自拆解文件第 4 节。
- 原片里参与动作的道具（被拿起、被递出、被踩到的）换成新场景里的等价物；不参与动作的配角、路人与陈设不进新片。
