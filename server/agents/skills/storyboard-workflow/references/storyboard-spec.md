# 逐镜拉片表共同法度

两种改编模式共用的规则：镜头继承、硬约束、粒度标尺和 `storyboard.md` 文件格式。模式专有的替换范围与改写边界在模式 reference 中。

## 镜头继承规则

结构层级与镜头划分逐个继承参考视频拆解文件第 4 节逐镜拉片表的结构：不增删、不拆分、不合并、不重排，两侧数量严格相等。

- 结构层级即拉片表的一行，顺序、名称照抄；参考视频某结构层级有 2 个镜头，改编后就是这 2 个镜头。
- 镜头数是硬约束：`storyboard.md` 继承同一份结构。需求描述点名要加的镜头是唯一例外：补在所属结构层级的末尾，正文按需求描述写，时间码后紧跟（新增），如 `**[00:05.000-00:06.500]**（新增）硬切，特写……`。时长按需求描述，没给就 2 秒；它后面所有镜头的时间码顺延同样的时长，总时长随之增加，在最终回复报人工复核；等比缩放做完再补。
- 时间码起止照抄参考视频。仅当新产品的物理交互耗时与原镜头不兼容时允许轻微调整，只允许调整当前镜头；对白装不下调整对应镜头的时间码。
- 每个镜头开头的切换方式和运镜描述（方向与快慢）照抄拆解文件第 4 节，不改写、不删；拆解文件没写「缓慢」的镜头，改编也不写。
- 目标时长与参考视频不一致时，全部时间码按「目标时长 ÷ 参考时长」等比缩放，相对节奏原样保留；缩放后再按对白容量规则微调。用户给定的对白按语速估算连全片都装不下时，对白一字不删，总时长放宽到装下为止，在最终回复报人工复核。
- 缩放后镜头变长的，按每 2 秒一个动作算出该镜头要装几个动作（不足 2 秒按 1 个），拆解文件第 4 节里该镜头的动作数不够就补。补的是完整的额外动作——每个有自己的开始和结束、正常速度 2 秒左右做得完（端详贝壳、举给镜头看、放进小桶）；把原动作切成更细的分段不算（「拿起」写成「伸手、握住、举起」时间并没有变多，等于慢动作）。补的动作插在原动作的起手之后、收尾之前，围着原动作手里的东西或该镜头已有的道具、产品做，不换景别、不加原片没有的运镜、不引入角色设定块之外的实体，不用「缓慢、慢慢、停留」这类靠拖慢来占时间的词。各动作按发生顺序用「先 / 随后 / 接着 / 最后」串成一段连续叙事，每个写清主体做什么、身体朝向和在画面中的位置。第一个和最后一个动作的景别、机位、主体位置姿态照抄拆解文件里该镜头的开头与结尾。

## 共同硬约束

- Storyline 中每一处产品名称、颜色、材质和设计细节必须来自产品事实清单；禁止沿用参考视频原产品的外观描述，禁止把非产品人物图中的服装当作产品。
- 出场人物的外貌、服装、发型描述必须与角色设定块中该人物那一条一致：人物在 Storyline 首次出现时用基准关键词完整交代，后续镜头不得出现与基准冲突的属性。
- 自行撰写的对白保持口语化、短句、断句和即时情绪，每句不超过 15 个单词；语言使用需求描述要求或用户已提供对白的语言，未指定时按目标受众选择，全片保持一致。用户提供的对白原文不受此限。
- 后续会互动的人物、道具或空间关系必须提前铺垫，避免突兀出现。
- 「出场人物/产品」列逐行标注该结构层级出场的人物与产品：人物用角色设定块的人物名，产品用产品名（单产品用品类词）；无人物或无产品的行只写实际出场的类型。单人单品视频该列照写全片常量，不省略。
- 文件正文只包含角色设定块、剪辑形式块与逐镜拉片表：不输出 JSON、不加代码块、正文前后不追加说明文字，不写拍摄建议、生成建议、执行要点、镜头节奏与 BGM 对照、连续性检查、转场逻辑说明或其他附加章节。

## Storyline 粒度标尺

正确的 Storyline 是一段按时间推进的动态叙事，信息密度介于"过粗"和"过细"之间。

正确粒度——每个镜头写清切换方式、景别、机位运镜、主体动作序列、产品交互、环境氛围和声音提示，全部用连贯叙事串联；镜头短就写短，一秒的镜头只写一个动作：

> **[00:00.000-00:05.000]** 开场，中景，固定机位平视正对金发女性（一位 25 岁上下的白人女性，身形偏瘦，浅金色直发到肩、发尾微微内扣，穿宽松的米色粗针织开衫和黑色直筒裤），她双手托住黑色漆皮鞋面、一字搭扣带的玛丽珍鞋展示，身体微微前倾，伸手指向镜头，英文女声说：{You need some cute and comfy shoes that you can wear to work. I got you ok. This is where you're gonna wanna start.}，背景为明亮卧室环境，无额外背景音乐，仅清晰收录说话人声。<br><br>**[00:05.000-00:10.800]** 硬切，特写，手持机位固定正对鞋内，手托住玛丽珍鞋翻转展示鞋垫上的黑色品牌字样，拇指反复按压米色软垫展示回弹，英文女声旁白继续：{They actually literally have like these cushions inside the shoes, these are the Mary Janes.}，背景为圣诞装饰居家客厅，虚化暖圣诞树灯光作为前景。<br><br>**[00:10.800-00:12.800]** 硬切，低角度中景，手持机位低角度对准上脚的鞋，她抬起脚翻转展示鞋面与方形粗跟橡胶底，英文女声旁白：{They have a little bit more of that block heel as well.}，背景依旧为亮灯圣诞树场景。

过粗——只写静态总结或抽象意图，无法据此拍摄或生成画面：

> 男子在户外跑步，展示产品防滑性能。

过细——把 Storyline 拆成逐镜子表格、加镜头编号列、加参考图列、加"与原片对照"段落，或在表格外写章节标题和叙事段落：

> | 镜号 | 时间码 | 景别 | 机位/运镜 | 画面内容描述 | 人物/产品动作细节 | 参考图提示 | 音效/BGM |

Storyline 单元格内只使用 `**[MM:SS.mmm-MM:SS.mmm]**` 精确时间码开头的文本段落和 `<br><br>` 连接，不使用子表格、列表、标题或其他结构化标记，不写模糊时间表述。

## 逐镜拉片表文件格式

目标文件路径为 `storyboard.md`，内容由角色设定块、剪辑形式块和完整 Markdown 逐镜拉片表组成：

```markdown
## 角色设定

- [人物「实体名」：性别年龄 + 体型身形 + 肤色与面部特征 + 发型发色 + 服装版型/颜色/材质 + 标志性特征]
- [产品「实体名」：品类 + 主体配色分区 + 材质与结构部件 + 关键设计细节 + 品牌标识及其位置]
- [场景「实体名」：空间类型 + 核心陈设 + 材质]

## 剪辑形式

[照抄拆解文件第 5 节]

## 逐镜拉片表 (Shot-by-Shot Script)

| 结构层级 | 出场人物/产品/场景 | Storyline |
| :--- | :--- | :--- |
| 原表第 1 行结构层级名称 | 人物、产品A | 改写后的 Storyline |
| 原表第 2 行结构层级名称 | 产品A、场景 | 改写后的 Storyline |
```

- 冒号前是类型加实体名，冒号后是该实体的锚点。实体名一律写：素材清单里有的取其名称列（单产品即品类词），推断补充的实体起一个辨识性短名。它是全流程的指代键——「出场人物/产品」列、visual_prompt 与 global_reference 都用它点名。
- 条目逐槽位写满，不用"一个男孩"这类模糊描述。
- 人物条目逐个出场人物一行，无出场人物的视频省略；场景条目按全片出现的场景逐个一行；产品条目逐产品一行，同一产品的多个视角合成一条。
- 同一结构层级中包含多个连续镜头时，继续放在同一个 `Storyline` 单元格内，用 `<br><br>` 连接。
