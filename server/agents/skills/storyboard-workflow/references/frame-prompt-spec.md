# 逐帧 visual_prompt 规范

## 概述

参考图与全局参考设定承载实体身份与外观；visual_prompt 只写该镜头的取景、机位、动作、光线与构图，不写实体外观。

## 槽位模板

一至两句简体中文，只写该镜头实际需要的画面信息：`[景别 + 机位或视角]，[人物的动作或状态]，[主体与产品或环境的关系]，[构图要点]`。

## 指代规则

- 人物用角色设定块的人物名指代，外观由参考图承载，不复述。
- 产品用品类词提及（"运动鞋""水杯"）；多产品同片时用角色设定块的产品名（"产品A「儿童凉鞋」"）点名，区分同框产品。
- 全片有多个场景时，每帧用角色设定块的场景名点明所在场景（"玄关""林间小径"）。
- 每帧出场的人物与产品以 `storyboard.md` 该镜头所在结构层级的「出场人物/产品」标注为准，不点名未出场的实体。

## 内容边界

只描述实拍画面的物理内容。字幕、贴纸、图形标注（箭头、圆圈、高亮框）、水印、平台 UI、进度条等后期叠加物不属于画面内容，不进入任何槽位（包括构图要点）。

忠实转写参考帧的取景与构图；外观由参考图承载，不转写参考帧里的原产品与原人物外观。

## 正误示例

正确（人物名指代 + 专注动作与构图 + 不写外观）：

> 低角度近景，机位贴地仰拍，画面齐膝只留小腿与双脚。男孩右脚抬起，鞋子侧面朝向镜头，双脚落在路缘石上，正午阳光从右上方投下短影，抬起的脚在画面正中偏下。

错误（描述实体外观 + 转写后期贴纸）：

> 低角度近景，穿修身蓝色牛仔裤的白人儿童抬起带侧孔的白色休闲运动鞋，左下角带有青色向下箭头标识。

错误（缺机位视角、缺光线、缺构图要点）：

> 低角度近景，Caucasian child 单脚抬起展示鞋侧，站在人行道边缘，鞋占画面下三分之一。
